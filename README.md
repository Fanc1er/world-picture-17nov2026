One image that sums up Tuesday 17 November 2026: world leaders converging on
Shenzhen before APEC opens (all eyes on the first US-China-Russia trilateral),
Nvidia's blowout quarter, Ukraine striking the Crimea bridge a second day, a
tanker mined east of Hormuz, Saudi-led strikes on Yemen, Mongolia's president
resigning, a Prague train collision, UK settlement sanctions, and Tokyo's
Nikkei sliding toward a bear market - drawn with PIL, one composition,
legible at 300 px.

The program copies `entry.png` to `/output/entry.png` (Node 22, standard library only).
The drawing script itself lives outside the entry: the shipped image is the work.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
